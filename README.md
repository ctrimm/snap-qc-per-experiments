# snap-qc-per-experiments

Experiments toward a **small, domain-specific language model for SNAP payment
accuracy** — a QC copilot trained on synthetic QC-style cases with
deterministic ground truth, validated against real QC public-use files.

Read [`NORTH_STAR.md`](NORTH_STAR.md) first: it defines the goal, the
synthetic-first data strategy, and the three validation gates (calibration,
transfer, LM eval) every experiment here must move.

## Repo map

- `src/synth/` — synthetic QC case generator: household sampler, deterministic
  benefit math (a stand-in for the QC Minimodel), and a variance injector that
  samples element/nature/cause from empirical QC distributions.
  Parameters are approximations, documented in `src/synth/params.py`.
- `experiments/` — one script + one chronicle doc per experiment.
  `build_dist.py` / `measure_effectiveness.py` are shared tooling;
  `dist.json` and `eff.json` are committed so the repo runs without the
  21MB real-data download.
- `experiments/TEMPLATE.md` — chronicle template. Every experiment gets:
  hypothesis (tied to the north star) → method → results → verdict → next
  steps.
- `terms.md` — glossary: evaluation metrics (L1, F1, macro F1, AUC) and
  generator vocabulary (finding, variance, element/nature/cause, materialize,
  importance weights, coins).

ID track complete: 8c + ID1–ID8 + fairness all landed. Verdict summary: **VALIDATED WITH CONDITIONS** — the generator calibrates, the P(error)-only ranker economics hold ($31/hr vs $22/hr), and the track's key scientific question is answered: **SD's low-PER P-alone reversal replicates in Idaho** (the second no-dollar-tail state), while UT's non-replication refines the panel rule to *no dollar tail → P-alone wins* (low PER alone does not imply it). Conditions: the transfer is mixed (element-accuracy signal, not finding — the mirror of NY2), the top-20% lift (1.40x) is modest, and the element macroF1 edge does not survive pristine conditions.

**ID verdict (POC complete, 2026-10-04).** Decision point 1 (ID2, ID8): ID-conditioned synthetic transfers on element accuracy (pristine +0.054 over national) but not on finding ranking (AUC +0.017, within noise) — the transferable signal lives in *which* errors, not *whether* error; contamination premium disclosed (~+0.08 acc). Decision point 2 (ID4, ID5): the P(error)-only ranker is a triage tool at 1.40x lift ($31/hr vs $22/hr), recovering 28.0% of error dollars at a 20% review budget — and it is the fairest configuration tested. **Recommended next step:** deploy the P(error)-alone structure for ID specifically — do not import PA's two-part, NY's direct, or UT's two-part winners; re-derive the ranking rule per state.
